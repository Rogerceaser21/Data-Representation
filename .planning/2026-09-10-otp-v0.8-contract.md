# otp-v0.8 contract · focus-on-open, required Time Out, no floating pad launcher

Approved by Igor 2026-09-10 ("go"). Foreman-built (Fable 5.1) on branch `claude/otp-v0.8`
from main `d1f9d19` (= otp-v0.7.1 + legend wording), one cold skeptic on the diff before ship.
The data contract of otp-v0.6 (`2026-09-09-otp-v0.6-contract.md` section 3: `sp1_*`,
`sp1_notes`, `sp1_selected_text`, `rubric_version` formats) is UNCHANGED; this release adds ONE
key and ONE column.

## 1. Scope

1. **Focus on open.** Tapping a criterion's `+` opens the note card AND focuses its textarea
   in the same tap (iPadOS raises the keyboard only for a focus inside the user gesture;
   an Apple Pencil tap gets Scribble instead). Overrides the otp-v0.7 "no auto-focus" rule
   at Igor's call. A locked record view (`CLOSED_RECORD_VIEW` / `.is-locked`) never focuses
   (read-only, nothing to type). Re-anchoring to another `+` focuses as well.
2. **Time Out, required, at the bottom.** A `time_out` field (`type="time"`, same look as
   Time In) in its own section directly above the Save & Lock action bar. It joins
   `REQUIRED_FIELDS`, so Save & Lock stays disabled until it is filled, like the other
   required fields (no message, no error UI: hard rule 12). No duration, no
   "after Time In" check (not asked). It is autosaved in the draft, posted, recorded in
   the Sheet, the backup email and the locked record view, exactly like Time In.
3. **No floating Evidence Pad launcher.** The top-right `#pad-open` pill and its wiring
   (click binding, `has-evi` toggle) are removed. Every other pad entry point stays:
   the five section pencils, the criterion note card pencil, the paperclips, the pad
   modal, the draft, the extraction, the upload at submit.

Out of scope: the R3 form (byte-identical), Supabase (payload stored verbatim, no
migration), the AI Next Steps idea (now v0.9), the dashboard.

## 2. Payload (POST JSON, `form:"otp"`) · exactly these 32 keys

```
form, teacher, curriculum, inspector, date, room_number, time_in, time_out, subject, school, grade,
support_teachers_cas, otp_ref, otp_aspect,
sp1_beginner, sp1_emerging, sp1_good, sp1_great, sp1_outstanding, sp1_selected_text,
sp1_present, sp1_partially_present, sp1_not_present, sp1_not_seen,
sp1_notes, rubric_version,
observer_comments, other_observations, next_step_1, next_step_2, next_step_3, evidence_pad_id
```

(`time_out` is the one new key, 31 -> 32; nothing else changes. Value: `HH:MM` as the
browser's `type="time"` input posts it, `""` never reaches the server because the field
is required.)

## 3. Sheet · `OTP Submissions` is 34 columns

The 33 of otp-v0.6 (order in `getOtpColumns()`), then **`time_out` appended as column 34**
(hard rule 1: append only; the existing header self-heal appends the trailing cell, rows
written before otp-v0.8 keep their positions and stay 33 cells wide).

## 4. Backend (`Assets/R3/apps-script`, shared with R3, redeploy in place @23)

- `00_Config.gs getOtpColumns()`: `'time_out'` appended after `'rubric_version'`.
- `01_doPost.gs` (OTP path only): the generic `record[col] = data[col]` mapping carries the
  value; the backup email gains `row('Time out', data.time_out)` directly after `Time in`.
- `02_doGet.gs`, `05_Supabase.gs`, `06_PadExtract.gs`: no change (record reads map every
  header; the mirror stores the payload verbatim).
- Harness `Assets/OTP/tests/gs-harness.mjs`: 34-column contract in order; header heal from a
  33-, 31-, 29- and 26-column tab appends exactly the right trailing cells; the email
  carries `Time out`; R3 scenarios byte-identical to origin/main.

## 5. Form (`Assets/OTP/src/otp-progress-form.html`)

- `openNotePanel`: after the card opens, `ta.focus({ preventScroll: true })` unless locked;
  the existing scroll-into-view keeps deciding the scroll. The `+` click handler and the
  scrim's `elementsFromPoint` route both end in `openNotePanel`, so both paths focus; the
  re-anchor path (close then `requestAnimationFrame` reopen) focuses in the reopen.
- Time Out: a `<section class="form-section">` with an `info-grid` holding ONE `info-cell`
  (`label.required-field` "Time Out", `input#time_out[name=time_out][type=time][required]`),
  placed after the Next Steps / Support 3 section and before the footer;
  `REQUIRED_FIELDS` gains `'time_out'`; the disabled-button title names Time Out.
- Launcher: the `#pad-open` markup and its `.float-link.pad` CSS removed; the pad init keeps
  binding everything else when the launcher is absent; `refreshEviState` drops the launcher
  toggle.
- Footer `Form · Progress in Lessons OTP · otp-v0.8`. `<title>` unchanged.

## 6. Tests (`Assets/OTP/tests/otp.spec.ts`, build first with `bash Assets/OTP/encrypt.sh`)

`CONTRACT_KEYS` = the section 2 list (32), the spec reads it from THIS document; new specs:
a `+` tap leaves `document.activeElement` on the card's textarea (form) and NOT in the
record view; Save & Lock stays disabled with every other required field filled until
`time_out` is filled, then enables; the posted payload carries `time_out`; the record view
shows `time_out`; `#pad-open` is absent while the five section pencils, the card pencil
and the paperclips exist; the draft round-trip restores `time_out`. Everything else as
otp-v0.7.1 (30 specs) unchanged.
